
## ⬇️ Installation

Currently, SpatioFlow is not yet available on Pypi. Once development of the package is done, SpatioFlow will be readily available on the Python Package Index.

Installing from the source:
```bash
git clone https://github.com/emmaevonk/SpatioFlow.git
cd SpatioFlow
pip install -e .
```

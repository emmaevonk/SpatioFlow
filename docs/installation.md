
## ⬇️ Installation

Currently, STAIA is not yet available on Pypi. Once development of the package is done, STAIA will be readily available on the Python Package Index.

Installing from the source:
```bash
git clone https://github.com/emmaevonk/STAIA.git
cd STAIA
pip install -e .
```

Minimum requirements: shown in [the requirements](https://github.com/emmaevonk/STAIA/) file on GitHub.
